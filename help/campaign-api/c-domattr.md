# DOMAttr (Clase)

Un nodo de tipo de atributo.

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [isId](p-domattr-isid.md) | true si el atributo es un tipo de ID. |
| [nombre](p-domattr-name.md) | Nombre del atributo. |
| [ownerElement](p-domattr-ownerelement.md) | Elemento con este atributo o nulo. |
| [especificado](p-domattr-specified.md) | true si el valor se especifica explícitamente (no es un valor implícito de forma predeterminada). |
| [valor](p-domattr-value.md) | Valor de texto de atributo. |
