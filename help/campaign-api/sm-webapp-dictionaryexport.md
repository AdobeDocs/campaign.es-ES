# DictionaryExport

Exporta cadenas para traducir.

```text
XML files = DictionaryExport ( XML where, Number exportOption, String exportFormat )
```

## Parámetros

**donde** la selección.

**exportOption** Opción de exportación

**exportFormat** Formato de exportación

## Valor(es) devuelto(s)

**archivos** Descripción de los archivos de salida
