# cusResource

Asignación de datos para replicación

## Métodos

| Método | Descripción |
| --- | --- |
| [CrearRecursoCus](sm-cusresource-createcusresource.md) | Cree automáticamente recursos personalizados con detección automática para campos/índice/vínculo/clave. |
| [Crear esquema FDAS](sm-cusresource-createfdaschema.md) | Cree automáticamente esquemas utilizados por FDA a partir de recursos personalizados ACS. |
| [GenerateCusResources](sm-cusresource-generatecusresources.md) | Insertar todos los recursos personalizados en el conjunto de recursos personalizados de ACS. |
