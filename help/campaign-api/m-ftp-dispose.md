# disponer

Libera los recursos utilizados por el objeto.

```text
dispose ()
```

## Parámetros

Ninguna.

## Valor devuelto

Ninguna.

## Observaciones

Este método es útil para liberar recursos utilizados por el objeto sin esperar a que el recolector de elementos no utilizados o el final del script finalice el objeto.

## Funciones

**Método de clase:** [FTP](c-ftp.md)

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
