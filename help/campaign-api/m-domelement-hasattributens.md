# hasAttributeNS

Pruebe la existencia de un atributo.

```text
hasAttributeNS (namespaceURI, localName)
```

## Parámetros

URI **namespaceURI** del atributo namespace.

Nombre de atributo **localName**.

## Valor devuelto

true si el atributo existe; en caso contrario, false.
