# DOMElement (Clase)

Un nodo de tipo de elemento.

## Métodos

| Método | Descripción |
| --- | --- |
| [toXMLString](m-domelement-toxmlstring.md) | Convierte un elemento en una cadena de caracteres. |
| [getFirstElement](m-domelement-getfirstelement.md) | Devuelve el primer elemento secundario al comprobar los criterios determinados. |
| [hasElement](m-domelement-haselement.md) | Comprueba si el elemento tiene un elemento secundario comprobando los criterios determinados. |
| [getValue](m-domelement-getvalue.md) | Devuelve el valor del nodo al que hace referencia el XPath dado. |
| [getBooleanValue](m-domelement-getbooleanvalue.md) | Devuelve el valor del nodo booleano al que hace referencia el XPath dado. |
| [getDateValue](m-domelement-getdatevalue.md) | Devuelve el valor de tipo fecha+hora de la referencia de nodo por el XPath dado. |
| [getNumberValue](m-domelement-getnumbervalue.md) | Devuelve el valor del nodo digital al que hace referencia el XPath dado. |
| [getElements](m-domelement-getelements.md) | Devuelve la lista de elementos secundarios con el nombre especificado que pertenecen a este elemento. |
| [getAttribute](m-domelement-getattribute.md) | Devuelve un valor de atributo. |
| [setAttribute](m-domelement-setattribute.md) | Cambie el valor de un atributo o cree un nuevo atributo. |
| [removeAttribute](m-domelement-removeattribute.md) | Eliminar un atributo. |
| [getElementsByTagName](m-domelement-getelementsbytagname.md) | Devuelve la lista de todos los elementos secundarios con el nombre especificado. |
| [getAttributeNS](m-domelement-getattributens.md) | Devuelve un valor de atributo. |
| [setAttributeNS](m-domelement-setattributens.md) | Cambie el valor de un atributo o cree un nuevo atributo. |
| [removeAttributeNS](m-domelement-removeattributens.md) | Eliminar un atributo. |
| [getElementsByTagNameNS](m-domelement-getelementsbytagnamens.md) | Devuelve la lista de todos los elementos secundarios con el nombre especificado. |
| [hasAttribute](m-domelement-hasattribute.md) | Pruebe la existencia de un atributo. |
| [hasAttributeNS](m-domelement-hasattributens.md) | Pruebe la existencia de un atributo. |
| [setIdAttribute](m-domelement-setidattribute.md) | Declara el atributo especificado como un atributo de tipo de ID. |
| [setIdAttributeNS](m-domelement-setidattributens.md) | Declara el atributo especificado como un atributo de tipo de ID. |
