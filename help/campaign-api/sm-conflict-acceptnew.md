# AceptarNuevo

Acepta la nueva versión como la versión actual.

```text
AcceptNew ( String conflictId )
```

## Parámetros

**ConflictId** Identificador de conflicto.

## Valor(es) devuelto(s)

Ninguna.

## Observaciones

El conflicto se elimina de la base de datos.

## Funciones

**Esquema:** [xtk:conflict](s-xtk-conflict.md)

**Estático:**

Sí
