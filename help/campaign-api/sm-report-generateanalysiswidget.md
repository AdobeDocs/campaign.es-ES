Genere el widget para mostrarlo.

```text
XML javascript = GenerateAnalysisWidget ( XML entity, String javascriptId, XML queryResult )
```

## Parámetros

Documento XML **entity** que describe el widget

**javascriptId** ID único del widget

Documento XML **queryResult** que contiene los datos
