# RestartTask

Obliga a reiniciar una o más tareas finalizadas.

```text
RestartTask ( String workflowId, String activityName )
```

## Parámetros

**workflowId** identificador o nombre interno del flujo de trabajo.

**activityName** Nombre de las actividades que se van a reiniciar

## Valor(es) devuelto(s)

Ninguna.
