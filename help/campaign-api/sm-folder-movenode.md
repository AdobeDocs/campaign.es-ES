# MoveNode

Mover carpeta en el árbol de navegación

```text
MoveNode ( String key, String parentKey, Number order, String fullName )
```

## Parámetros

**key** Clave de nodo

**parentKey** clave principal

**pedido** Nuevo índice de nodo

**fullName** Nombre completo (no vacío para cambiar el elemento principal en el árbol)

Ninguna.
