# RecomputeStats

Calcular las estadísticas de envío y seguimiento de una acción de envío.

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## Parámetros

**deliveryId** Identificador de envío

**dirtyFlags** Campo de bits que describe lo que hay que recalcular (consulte la enumeración &#39;nms:delivery:dirtyFlags&#39;).

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sí
