Actualizar la base de datos mediante enumeraciones corregidas.

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## Parámetros

**donde** las enumeraciones filtran.

**fromDate** Fecha de inicio para las respuestas a la encuesta.

**refreshHit** Actualización de visita.
