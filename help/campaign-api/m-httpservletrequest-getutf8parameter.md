# getUTF8Parameter

Devuelve el valor (codificado en UTF-8) de un parámetro de la consulta.

```text
getUTF8Parameter (name)
```

## Parámetros

**nombre** Nombre del parámetro.

## Valor devuelto

El valor del parámetro solicitado.

## Funciones

**Método de clase:** [HttpServletRequest](c-httpservletrequest.md)

**Disponible en:**

* JSSP
* WebApp
