# FileEdit

Este control permite introducir un nombre de archivo.

![Control FileEdit](assets/fileedit.56228d2a.png)

## Propiedades

**backColor - string** Color de fondo (btnshasow, blanco).

**border - string** Cambia el estilo del borde durante el control (solid, double, inset, begin, none).

**dlgType - string** Tipo de ventana de selección de archivos (save, opendir, savedir).

**filtros: cadena** Lista de filtros

**tamaño de fuente - entero** Cambia el tamaño de fuente.

**etiqueta - cadena** Etiqueta asociada.

**lastPath - string** Ruta de acceso de la ventana de selección de archivos.

**loadContent - booleano** Carga el contenido de un archivo.

**nolabel - booleano**: oculta la etiqueta asociada.

**readOnly - boolean** fuerza al control a ser de solo lectura.

**obligatorio - booleano** El campo es obligatorio.

**título - cadena** Título de la ventana de selección

**xpathCopyName - xpath** Ruta para almacenar el nombre de archivo (con su extensión).

**xpathType - xpath** Tipo de archivo (texto o XML)
