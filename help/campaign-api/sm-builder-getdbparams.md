# GetDbParams

Recupera los parámetros actuales de la fuente de datos.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## Parámetros

Ninguna.

## Valor(es) devuelto(s)

**dbcnx** definición de origen de datos

**dbParameters** Actualice los espacios de nombres y tablespaces.

**Esquema:** [xtk:builder](s-xtk-builder.md)

**Estático:**

Sí
