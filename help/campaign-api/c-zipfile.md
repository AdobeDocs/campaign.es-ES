# ZipFile (Clase)

Manipula archivos Zip.

## Métodos

| Método | Descripción |
| --- | --- |
| [ArchivoZip](m-zipfile-zipfile.md) | Crea un nuevo objeto Zip asociado a un archivo. |
| [eliminar](m-zipfile-dispose.md) | Libera los recursos utilizados por el objeto. |
| [abrir](m-zipfile-open.md) | Carga un archivo existente. |
| [getEntry](m-zipfile-getentry.md) | Extrae un archivo del archivo. |
| [setEntry](m-zipfile-setentry.md) | Agrega o actualiza un archivo en el archivo. |
| [guardar](m-zipfile-save.md) | Guarda el archivo. |

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [fileCount](p-zipfile-filecount.md) | Devuelve el número de archivos del archivo. |
