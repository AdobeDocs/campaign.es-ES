# DropSelection

Mover la selección a una carpeta del árbol de navegación

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## Parámetros

**schema** ID de esquema de selección

**entityFolder** ID de la carpeta de destino

**selectionList** selección para mover

**folderDestId** carpeta de destino

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [xtk:folder](s-xtk-folder.md)

**Estático:**

Sí
