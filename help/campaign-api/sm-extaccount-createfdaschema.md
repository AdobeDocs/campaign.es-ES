# CrearEsquemaFDA

Crea el esquema de trabajo en la base de datos

```text
CreateFDASchema ( String server, String account, String password, String port, String options, String schema )
```

## Parámetros

**servidor** Dirección del servidor

**cuenta** Nombre (o inicio de sesión) de la cuenta

**contraseña** Contraseña asociada a la cuenta

**puerto** puerto del servidor

**opciones** Opciones de conexión

**esquema** Nombre de esquema

## Valor(es) devuelto(s)

Ninguna.
