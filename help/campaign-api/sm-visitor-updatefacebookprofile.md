# updateFacebookProfile

```text
Number result = updateFacebookProfile ( String accessToken )
```

## Parámetros

**token de acceso**

## Valor(es) devuelto(s)

**result** Devuelve el ID de la entidad de Adobe Campaign que coincide con el token de acceso de Facebook. Si el código es diferente de 0, la llamada se realizó correctamente.
