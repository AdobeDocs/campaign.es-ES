# EnumerationValue, clase

Representa la definición de un valor de enumeración.

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [etiqueta](p-enumerationvalue-label.md) | Devuelve una cadena de caracteres que proporciona la descripción breve del valor de enumeración actual. |
| [descripción](p-enumerationvalue-description.md) | Devuelve una cadena de caracteres que proporciona la descripción del valor de enumeración actual. |
| [valor](p-enumerationvalue-value.md) | Devuelve una cadena de caracteres que proporciona el valor del valor de enumeración actual. |
| [nombre](p-enumerationvalue-name.md) | Devuelve una cadena de caracteres que proporciona el nombre del valor de enumeración actual. |
| [imagen](p-enumerationvalue-image.md) | Devuelve una cadena de caracteres que proporciona el nombre de la imagen del valor de enumeración actual. |
| [enabledIf](p-enumerationvalue-enabledif.md) | Devuelve una cadena de caracteres que proporciona las condiciones de validez del valor de enumeración actual. |
