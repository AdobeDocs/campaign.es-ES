# LoadChildren

Cargar la lista de tareas secundarias de un nodo determinado

```text
XML result = LoadChildren ( String parentKey, String folderFilter, Boolean writeAccess, String fullName, Boolean sort )
```

## Parámetros

**parentKey** clave principal

**folderFilter** filtro en carpetas

**writeAccess** La carpeta devuelta debe poder escribirse

**fullName** Nombre completo del nodo seleccionado

**ordenar** por orden alfabético

## Valor(es) devuelto(s)

**resultado** Documento de resultado
