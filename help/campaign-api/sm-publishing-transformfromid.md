# TransformFromId

Transformación de publicación desde un ID de contenido

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Parámetros

**publishingId** Identificador de plantilla de publicación

**modelName**: nombre de la plantilla de transformación

**contentId** Identificador de contenido

## Valor(es) devuelto(s)

**formato** Formato de salida

**resultado** resultado de transformación
