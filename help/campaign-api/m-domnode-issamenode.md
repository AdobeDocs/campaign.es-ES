# isSameNode

Comprueba si la referencia dada representa el mismo nodo.

```text
isSameNode ()
```

## Parámetros

Ninguna.

## Valor devuelto

true si ambas referencias representan el mismo nodo; en caso contrario, false.

## Observaciones

Este método debe utilizarse para comparar dos referencias, los operadores JavaScript == y === no pueden utilizarse.
