
## Parámetros

ID de oferta **offerId**

**tipo** Tipo de aprobación (segmentación=0, contenido=1)

**offerSpaces** espacios de oferta para aprobar

**rechazado** rechazar aprobación de elegibilidad

**comentario** comentario
