# GenerateSingleLevelDimension

Generar una dimensión de un solo nivel basada en un campo.

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## Parámetros

**dimensión** Dimension para ingresar

**campo** Campo o expresión usado

## Valor(es) devuelto(s)

**result** ingresó una dimensión
