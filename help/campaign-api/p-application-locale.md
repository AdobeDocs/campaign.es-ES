# locale

Devuelve una cadena de caracteres que coincide con la instancia Local.

```text
locale
```

## Observaciones

El valor de Local es un código que define la configuración regional. Se compone de un código de idioma seguido de un código de país, separado por &quot;-&quot;. Ejemplos de valores:

* en-US - Inglés, Estados Unidos
* es-ES - Inglés, Reino Unido
* fr-FR - Francés, Francia
* de-DE - Alemán, Alemania
* es-ES - Español, España
