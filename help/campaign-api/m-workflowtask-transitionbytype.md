# transitionByType

Devuelve la transición correspondiente al tipo determinado.

```text
transitionByType (type)
```

## Parámetros

**type** Tipo de transición.

## Valor devuelto

La primera transición que tiene el tipo pasado como parámetro; de lo contrario, es nulo si la actividad no tiene una transición de este tipo.
