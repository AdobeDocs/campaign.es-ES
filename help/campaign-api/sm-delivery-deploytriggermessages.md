# DeployTriggerMessages

Publicar los mensajes transaccionales seleccionados en las instancias de ejecución

```text
DeployTriggerMessages ( XML deliveries, Boolean localPublish )
```

## Parámetros

**envíos**: filtre las condiciones para definir los mensajes transaccionales que se van a implementar.

**localPublish** ¿Desea publicar solo en la instancia de control?

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sí
