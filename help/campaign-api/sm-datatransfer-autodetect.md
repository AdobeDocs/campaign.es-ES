# AutoDetect

Inicia una detección automática y devuelve las primeras líneas del archivo

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## Parámetros

**fileName** Nombre de archivo

**página de códigos** Codificación de caracteres

## Valor(es) devuelto(s)

**result** Devuelve las primeras líneas del archivo
