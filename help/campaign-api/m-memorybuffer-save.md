# guardar

> Advertencia:
>
> El acceso a través de las API de archivo está limitado a **var**, **sftp** y a las carpetas temporales de Adobe Campaign.

Guarda el contenido del búfer en un archivo.

```text
save (filename)
```

## Parámetros

**nombre de archivo** Nombre del archivo que se va a guardar.

## Valor devuelto

Ninguna.
