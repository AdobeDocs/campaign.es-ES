# UpdateLevelName

Actualiza el nombre interno de un nivel en función de su expresión.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Parámetros

**nivel** nivel a modificar

**dimensión** Dimensión principal del nivel

## Valor(es) devuelto(s)

**resultado** nivel modificado
