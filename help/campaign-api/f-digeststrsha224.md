# digestStrSha224

Calcula el hash SHA-224 de una cadena de caracteres. La cadena se codifica automáticamente en UTF-8 antes del cálculo.

```text
digestStrSha224 (string)
```

## Parámetros

**cadena** Cadena en la que se va a calcular el hash.

## Valor devuelto

El hash SHA-224 de la cadena pasada como parámetro.

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Envío del mensaje
* Regla de tipología
* Importación
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
