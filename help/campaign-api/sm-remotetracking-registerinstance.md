# RegisterInstance

Se utiliza para aprobar una instancia de seguimiento

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## Parámetros

**instanceName** Nombre de la instancia que se va a aprobar

**dbId** Identificador de base de datos para el cliente que realiza una entrega

**lang** idioma de instancia

## Valor(es) devuelto(s)

Ninguna.
