# ResolvePackageReferences

Resuelve dependencias en el paquete

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Parámetros

**parameters** elemento XML que contiene el paquete que se va a importar.

## Valor(es) devuelto(s)

**patchedPackage** paquete procesado.

**warningNb** Número de advertencias generadas.
