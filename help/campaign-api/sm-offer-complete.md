# Completar

Completa una oferta creada a partir de una plantilla (gestión de coherencia y asignación de espacio).

```text
XML offerOut = Complete ( XML offerIn )
```

## Parámetros

**offerIn** oferta entrante

## Valor(es) devuelto(s)

**offerOut** oferta actualizada
