# SchemaKey (Clase)

Representa la definición de una clave.

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [etiqueta](p-schemakey-label.md) | Devuelve la descripción breve de la clave. |
| [descripción](p-schemakey-description.md) | Devuelve la descripción de la clave. |
| [nombre](p-schemakey-name.md) | Devuelve el identificador de la clave. |
| [isInternal](p-schemakey-isinternal.md) | Devuelve verdadero si la clave es la clave interna. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | Devuelve true si los campos de la clave pueden estar vacíos (debe introducirse al menos uno de los campos). |
| [campos](p-schemakey-fields.md) | Devuelve una tabla que contiene el campo de campos ( [SchemaNode](c-schemanode.md) ) de la clave. |

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
