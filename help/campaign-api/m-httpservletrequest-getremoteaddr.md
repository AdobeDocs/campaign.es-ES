# getRemoteAddress

Devuelve la dirección IP del cliente o el último proxy que envió una solicitud.

```text
getRemoteAddr ()
```

## Parámetros

Ninguna.

## Valor devuelto

Cadena que contiene la dirección IP del cliente que envió la consulta.

## Funciones

**Método de clase:** [HttpServletRequest](c-httpservletrequest.md)

**Disponible en:**

* JSSP
* WebApp
