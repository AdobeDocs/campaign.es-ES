# sendError

Devuelve una respuesta de error utilizando el código de error pasado como parámetro.

```text
sendError (errorCode)
```

## Parámetros

**errorCode**: el código de error HTTP.

## Valor devuelto

Ninguna.

## Funciones

**Método de clase:** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en:**

* JSSP
* WebApp
