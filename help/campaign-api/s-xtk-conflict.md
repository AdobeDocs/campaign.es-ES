# conflicto

> Advertencia: Esta función está disponible para un entorno local.

Almacenamiento temporal de las entidades en conflicto.

## Métodos

| Método | Descripción |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | Mantiene la versión actual. |
| [AceptarNuevo](sm-conflict-acceptnew.md) | Acepta la nueva versión como la versión actual. |
| [SetResolved](sm-conflict-setresolved.md) | Declara una entidad como que no tiene más conflictos. |

## Métodos genéricos

| Método | Descripción |
| --- | --- |
| [crear](f-create.md) | Crea una nueva entidad correspondiente a un esquema determinado. |
| [cargar](f-load.md) | Carga y devuelve una entidad correspondiente a un esquema y una clave determinados. |
| [guardar](m-entity-save.md) | Guarda una entidad en la base de datos. |
