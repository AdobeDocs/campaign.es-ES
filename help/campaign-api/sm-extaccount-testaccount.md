# TestAccount

Realiza una prueba de conexión

```text
TestAccount ( Number type, String server, String account, String password, String port, String options )
```

## Parámetros

**tipo** Tipo de cuenta

**servidor** Dirección del servidor

**cuenta** Nombre (o inicio de sesión) de la cuenta

**contraseña** Contraseña asociada a la cuenta

**puerto** puerto del servidor

**opciones** Opciones de conexión

## Valor(es) devuelto(s)

Ninguna.
