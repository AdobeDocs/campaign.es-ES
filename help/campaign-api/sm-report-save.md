# Guardar

Guarda un informe ya generado en la base de datos.

```text
XML result = Save ( XML data, String reportName )
```

## Parámetros

**datos** Datos usados por los informes

**reportName** Nombre interno del informe

## Valor(es) devuelto(s)

**resultado** Identificador único y fecha de registro
