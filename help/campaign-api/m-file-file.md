# Archivo

Crea un nuevo objeto asociado a un archivo.

```text
File (filename)
```

## Parámetros

**nombre de archivo** Nombre del archivo que se va a leer o crear.

## Valor devuelto

Ninguna.

## Observaciones

Ejemplo:

```javascript
var f = new File("/tmp/file.txt")
```
