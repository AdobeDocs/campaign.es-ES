# BuildFromCube

Crea la lista basándose en una selección de celdas de un cubo.

```text
BuildFromCube ( Number listId, XML conditions )
```

## Parámetros

**listId** Identificador de lista

**condiciones** Condiciones para definir la generación de listas

## Valor(es) devuelto(s)

Ninguna.
