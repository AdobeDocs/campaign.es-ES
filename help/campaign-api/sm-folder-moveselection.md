# MoverSelección

Mover la selección a una carpeta del árbol de navegación

```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## Parámetros

**schemaId** ID de esquema de selección

**entityFolder** ID de la carpeta de destino

**selectionList** selección para mover

**key** Clave de nodo

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [xtk:folder](s-xtk-folder.md)

**Estático:**

Sí
