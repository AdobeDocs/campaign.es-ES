# Limpiar envíos

Especifica que el servidor intermediario debe eliminar determinados envíos.

```text
CleanupDeliveries ( String deliveryId )
```

## Parámetros

**deliveryId**: lista de identificadores de envío en la base de datos de envío (separados por comas)

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sí
