# GetNewIds

Recopila una lista de identificadores de claves internas para la base de datos.

```text
String idList = GetNewIds ( Number count )
```

## Parámetros

**count** Número de identificadores que este método debe devolver

## Valor(es) devuelto(s)

**idList** Lista de identificadores separados por comas
