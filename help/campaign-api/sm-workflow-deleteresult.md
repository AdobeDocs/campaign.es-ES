# DeleteResult

Borra los resultados de una o más actividades.

```text
DeleteResult ( String workflowId, String activityName )
```

## Parámetros

**workflowId** identificador o nombre interno del flujo de trabajo.

**activityName** Nombre de las actividades cuyos resultados desea borrar

## Valor(es) devuelto(s)

Ninguna.
