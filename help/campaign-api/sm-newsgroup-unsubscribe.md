# Cancelar la suscripción

Cancelar la suscripción de un operador a un foro de debate.

```text
Unsubscribe ( Number operatorId, String schema, Number entityId )
```

## Parámetros

**operatorId** ID de operador

**schema**: esquema de la entidad vinculada al foro

**entityId** ID de la entidad vinculada al foro

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:newsgroup](s-nms-newsgroup.md)

**Estático:**

Sí
