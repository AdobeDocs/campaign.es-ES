# EvaluateJavaScriptTemplate

Evaluación de plantillas JavaScript (JST).

```text
[ XML context, String result ] = EvaluateJavaScriptTemplate ( String name, String template, XML context )
```

## Parámetros

**name** Nombre de script.

**plantilla** documento para evaluar.

**contexto** Contexto al evaluar el documento.

## Valor(es) devuelto(s)

**contexto** Contexto al evaluar el documento.

**resultado** Documento resultante de la evaluación.
