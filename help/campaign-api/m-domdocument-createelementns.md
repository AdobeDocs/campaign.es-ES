# createElementNS

Crea un nuevo elemento con el nombre y el área de nombres especificados.

```text
createElementNS (namespaceURI, qualifiedName)
```

## Parámetros

**namespaceURI**: URI de espacio de nombres.

**qualificationName** Nombre completo del elemento que se va a crear.

## Valor devuelto

[elemento](c-domelement.md) creado.
