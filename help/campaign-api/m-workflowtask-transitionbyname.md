# transitionByName

Devuelve las transiciones correspondientes al nombre dado.

```text
transitionByName (name)
```

## Parámetros

**nombre** Nombre de la transición.

## Valor devuelto

La transición con el nombre pasado como parámetro; de lo contrario, es nula si la actividad no tiene una transición con este nombre.
