# replaceChild

Reemplace un nodo.

```text
replaceChild (newChild, oldChild)
```

## Parámetros

**nuevoNodo** secundario para insertar.

**oldChild** nodo que reemplazar.

## Valor devuelto

Nodo reemplazado.
