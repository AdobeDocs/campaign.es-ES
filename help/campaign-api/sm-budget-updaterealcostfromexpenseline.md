# ActualizarCosteRealDeLíneaDeGastos

Actualiza el envío real o el importe de la tarea mediante el elemento de línea.

```text
UpdateRealCostFromExpenseLine ( Number id, String schema, XML budgetParameters )
```

## Parámetros

**id** Identificador de envío/tarea

**esquema** esquema de entidad (envío/tarea)

**budgetParameters** Elemento de presupuesto en la entidad

Ninguna.
