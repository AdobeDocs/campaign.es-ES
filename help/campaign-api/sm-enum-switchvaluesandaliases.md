# SwitchValuesAndAliases

Convertir un valor en un alias y viceversa.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Parámetros

**enumeraciones**: colección de enumeraciones que se van a convertir.

Modo de conversión **mode**: debe ser &#39;ValuesToAliases&#39; o &#39;AliasesToValues&#39;.

## Valor(es) devuelto(s)

Ninguna.
