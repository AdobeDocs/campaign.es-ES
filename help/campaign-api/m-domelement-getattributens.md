# getAttributeNS

Devuelve un valor de atributo.

```text
getAttributeNS (namespaceURI, localName)
```

## Parámetros

URI **namespaceURI** del atributo namespace.

Nombre de atributo **localName**.

## Valor devuelto

Valor de texto de atributo.
