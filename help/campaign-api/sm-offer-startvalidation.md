# StartValidation

Enviar la oferta para su aprobación.

```text
StartValidation ( String offerId, Number type, XML offerSpaces )
```

## Parámetros

ID de oferta **offerId**.

**tipo** Tipo de aprobación (segmentación=0, contenido=1)

**offerSpaces** espacios de oferta para aprobar

Ninguna.
