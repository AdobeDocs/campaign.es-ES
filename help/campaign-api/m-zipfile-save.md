# guardar

Guarda el archivo.

```text
save ( [filename ] [, overwrite ])
```

## Parámetros

**nombre de archivo** Nombre del archivo. Si el nombre no se especifica o está vacío, el archivo se guarda con su nombre original.

**sobrescribir** Si tiene el valor &#39;false&#39;, el archivo no se guardará si ya existe un archivo con este nombre y se generará una excepción.

## Valor devuelto

Ninguna.
