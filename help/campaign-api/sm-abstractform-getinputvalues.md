# GetInputValues

Busca los posibles valores de una zona de entrada en un formulario.

```text
XML options = GetInputValues ( String schema, XML input )
```

## Parámetros

**esquema** Esquema de edición de encuesta.

**input** Zona de entrada.

## Valor(es) devuelto(s)

**options** valores posibles para esta zona de entrada.
