# Transformación

Transformación de la publicación desde un contenido

```text
[ String format, String result ] = Transform ( String publishingId, String modelName, XML content )
```

## Parámetros

**publishingId** Identificador de plantilla de publicación

**modelName**: nombre de la plantilla de transformación

**contenido** Datos de contenido para transformar

## Valor(es) devuelto(s)

**formato** Formato de salida

**resultado** resultado de transformación
