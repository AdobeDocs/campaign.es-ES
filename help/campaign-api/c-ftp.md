# FTP (Clase)

Un objeto FTP permite realizar diversas operaciones mediante el protocolo FTP.

## Métodos

| Método | Descripción |
| --- | --- |
| [FTP](m-ftp-ftp.md) | Crea un nuevo objeto para ejecutar comandos de FTP. |
| [eliminar](m-ftp-dispose.md) | Libera los recursos utilizados por el objeto. |
| [lista](m-ftp-list.md) | Devuelve la lista de archivos del servidor en un directorio especificado. |
| [descargar](m-ftp-download.md) | Descarga un archivo desde el servidor a un archivo local o a la memoria. |
| [cargar](m-ftp-upload.md) | Descargar un archivo desde un archivo local a un servidor FTP. |
| [setFile](m-ftp-setfile.md) | Define el modo de transferencia y el archivo de recepción. |
