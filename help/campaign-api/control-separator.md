# Separador

Mostrar un separador con un texto y una imagen.

![Control separador](assets/separator.70317a27.png)

## Propiedades

**direction - cadena** horizontal de forma predeterminada.

**img - cadena** Imagen asociada.

**etiqueta - cadena** Texto para mostrar.

## Observaciones

Ejemplo:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
