# hasElement

Comprueba si el elemento tiene un elemento secundario comprobando los criterios determinados.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Parámetros

**tagName** Nombre del elemento buscado.

**attrName** Nombre de un atributo que debe comprobar un valor determinado.

Valor de atributo **attrValue**.

## Valor devuelto

true si el elemento tiene un elemento secundario al comprobar los datos proporcionados; en caso contrario, false.
