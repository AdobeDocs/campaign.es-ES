# Uso de XML

Muchas API de JavaScript toman objetos de tipo XML como parámetros o los devuelven. Las versiones anteriores de Adobe Campaign utilizaban la extensión E4X de JavaScript para esto, lo que permitía manipular directamente los elementos XML en el idioma. Sin embargo, esta tecnología se está abandonando lentamente.

Para reemplazar esta tecnología, se han agregado nuevos objetos para manipular documentos XML. Reanudan un subconjunto de la interfaz del Modelo de objetos de documento (DOM) con algunas extensiones. También hay disponible un objeto de notación para crear fácilmente documentos XML, es una versión simplificada de la convención JXON BadgetFish.

## Interfaz DOM

Un objeto [DOMDocument](c-domdocument.md) es un documento XML. Se puede crear a partir de una cadena de caracteres, un objeto JSON o directamente desde un archivo. Este es un ejemplo de creación de un documento DOM:

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

Esta interfaz forma parte de la especificación del W3C con varias diferencias importantes:

* Las funciones getElements\*, así como las propiedades childNodes y attributes devuelven una tabla JavaScript en lugar de un objeto NodeList, esto permite el uso de las propias funciones de las tablas: forEach, map, ...
* Algunas propiedades devuelven una cadena vacía en lugar de un valor nulo cuando no se ha especificado el valor.

Además, se han añadido ciertas funciones de utilidad y algunas extensiones no estándar. Por ejemplo, para leer o modificar un atributo, solo es necesario escribir:

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

en lugar de:

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

Asignar un atributo con la propiedad $name puede llevar una cadena, un booleano, una fecha o un número, el valor se convertirá automáticamente en una cadena de caracteres:

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JSON es una convención de notación para objetos de JavaScript para crear fácilmente documentos XML. Esta notación no permite crear todos los documentos XML posibles. Por ejemplo, no permite especificar un elemento con el mismo nombre que un atributo y los espacios de nombres no se administran. Está adaptado para documentos de Adobe Campaign. Para necesidades más complejas, siempre puede utilizar funciones DOM tradicionales (analizar o crear elemento por elemento). El objeto XML está representado por un objeto JavaScript cuyas propiedades coinciden con los elementos y atributos. El tipo de valor determina si tiene que ver con un elemento o un atributo.

* Cadena Atributo cuyo valor es la cadena de caracteres
* Booleano Atributo cuyo valor puede ser &quot;true&quot; o &quot;false&quot;
* Número Atributo cuyo valor es la representación de número decimal
* Fecha Atributo cuyo valor es la representación ISO-8601 de la fecha y la hora
* Objeto Un elemento
* Matriz Una lista de elementos

Se utiliza una propiedad especial bajo el nombre $ para el contenido de texto de un elemento Ejemplos:

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

Cuando las propiedades contienen caracteres especiales que no son identificadores JavaScript válidos, deben ponerse entre comillas.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

Los objetos JSON se pueden utilizar en argumentos en cualquier lugar donde una función anticipa un documento o elemento XML. Por ejemplo:

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

es equivalente a:

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

Es importante tener en cuenta que la manipulación de documentos XML se realiza mediante objetos DOM, los objetos JSON son utilidades utilizadas únicamente para la inicialización. Es más útil crear un documento XML a partir de una estructura JavaScript literal, especialmente cuando el documento contiene partes variables.
