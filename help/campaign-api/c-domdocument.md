# DOMDocument, clase

Documento XML.

## Métodos

| Método | Descripción |
| --- | --- |
| [DOMDocument](m-domdocument-domdocument.md) | Crea un nuevo documento. |
| [fromXMLString](m-domdocument-fromxmlstring.md) | Crea un nuevo documento a partir de una cadena de caracteres XML. |
| [deJXON](m-domdocument-fromjxon.md) | Crea un nuevo documento a partir de un objeto JSON. |
| [cargar](m-domdocument-load.md) | Crea un nuevo documento a partir de un archivo XML. |
| [toXMLString](m-domdocument-toxmlstring.md) | Convierte el documento XML en una cadena de caracteres. |
| [createElement](m-domdocument-createelement.md) | Crea un nuevo elemento. |
| [createElementNS](m-domdocument-createelementns.md) | Crea un nuevo elemento con el nombre y el área de nombres especificados. |
| [createTextNode](m-domdocument-createtextnode.md) | Crea un nuevo nodo de texto. |
| [createComment](m-domdocument-createcomment.md) | Crea un nuevo nodo de tipo de comentario. |
| [createCDATASection](m-domdocument-createcdatasection.md) | Crea un nuevo nodo de tipo CDATA. |
| [createProcessingInstruction](m-domdocument-createprocessinginstruction.md) | Crea una nueva instrucción de procesamiento. |
| [createEntityReference](m-domdocument-createentityreference.md) | Crea una nueva referencia de entidad. |
| [getElementsByTagName](m-domdocument-getelementsbytagname.md) | Devuelve la lista de todos los elementos con el nombre especificado. |
| [getElementsByTagNameNS](m-domdocument-getelementsbytagnamens.md) | Devuelve la lista de todos los elementos del documento con el nombre y el área de nombres especificados. |
| [getElementById](m-domdocument-getelementbyid.md) | Devuelve el elemento con el identificador especificado. |
| [importNode](m-domdocument-importnode.md) | Crea una copia de nodo desde otro documento. |
| [normalizeDocument](m-domdocument-normalizedocument.md) | Normaliza el documento: las referencias de entidad se sustituyen y los nodos de texto adyacentes se fusionan. |
| [cambiar el nombre del nodo](m-domdocument-renamenode.md) | Cambia el nombre de un elemento o un atributo. |
