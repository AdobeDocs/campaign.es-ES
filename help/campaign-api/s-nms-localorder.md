# localOrder

Pedidos de campaña locales en un paquete para marketing distribuido

## Métodos

| Método | Descripción |
| --- | --- |
| [Cancelar](sm-localorder-cancel.md) | Cancele el pedido. |
| [CrearCatálogo](sm-localorder-createfromcatalog.md) | Cree un pedido a partir de un paquete. |
| [EvaluarContenido](sm-localorder-evaluatecontent.md) | Evalúa el contenido de un envío vinculado a un pedido. Esta evaluación se realizará al realizar pedidos con derechos de operador y antes de crear la campaña local. |
| [EvaluateContentFromId](sm-localorder-evaluatecontentfromid.md) | Evalúa el contenido de un envío vinculado a un pedido. Esta evaluación se realizará al realizar pedidos con derechos de operador y antes de crear la campaña local. |
| [EvaluateDeliveryBudget](sm-localorder-evaluatedeliverybudget.md) | Evaluar el presupuesto del envío. |
| [EvaluateTarget](sm-localorder-evaluatetarget.md) | Evalúa la segmentación de la campaña para cada envío de campaña vinculado a un pedido. Esta evaluación se realizará al realizar pedidos con derechos de operador y antes de crear la campaña local. |
| [EvaluateTargetFromId](sm-localorder-evaluatetargetfromid.md) | Evalúa la segmentación de la campaña para cada envío de campaña vinculado a un pedido. Esta evaluación se realizará al realizar pedidos con derechos de operador y antes de crear la campaña local. |
| [EjecutarDestino](sm-localorder-executetarget.md) | Ejecuta la segmentación de campaña vinculada al pedido. |
| [Reservar](sm-localorder-reserve.md) | Pedido. |
| [Validación](sm-localorder-validation.md) | Apruebe el pedido. |
