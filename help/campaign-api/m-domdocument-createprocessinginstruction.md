# createProcessingInstruction

Crea una nueva instrucción de procesamiento.

```text
createProcessingInstruction (target, data)
```

## Parámetros

**target**: destino de instrucción de procesamiento, por ejemplo &lt;?php ... ?>.

**datos** Cadena de caracteres para insertar en la instrucción.

## Valor devuelto

[instrucción de procesamiento](c-domnode.md) creada.
