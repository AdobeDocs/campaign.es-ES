# remoteTracking

Acceso al servicio de administración de seguimiento remoto

## Métodos

| Método | Descripción |
| --- | --- |
| [Crear instancia](sm-remotetracking-createinstance.md) | Se utiliza para crear una instancia de seguimiento |
| [CreateInstanceEx](sm-remotetracking-createinstanceex.md) | Se utiliza para crear una instancia de seguimiento |
| [GetTrackingInfo](sm-remotetracking-gettrackinginfo.md) | Permite a un servidor de redirección remota descargar información sobre una acción de envío. |
| [GetTrackingLogs](sm-remotetracking-gettrackinglogs.md) | Permite recopilar los registros de seguimiento generados por el servicio de redirección y seguimiento web. |
| [GetTrackingLogs4](sm-remotetracking-gettrackinglogs4.md) | Permite recuperar los registros de seguimiento generados por el servidor de redirección remota y seguimiento web, utilizando un formato de entrada de 4.00. |
| [PushRelayInfo](sm-remotetracking-pushrelayinfo.md) | Permite cargar información sobre un envío en los servidores de seguimiento remoto. |
| [PushTrackingInfo](sm-remotetracking-pushtrackinginfo.md) | Permite cargar en el servidor de seguimiento remoto toda la información relativa a un envío. |
| [RegisterInstance](sm-remotetracking-registerinstance.md) | Se utiliza para aprobar una instancia de seguimiento |
