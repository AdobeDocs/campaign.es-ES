# CreateFromModel

Creación de un envío a partir de una plantilla (desde su nombre interno).

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## Parámetros

**scenarioName** nombre interno de la plantilla de envíos

**contenido** contenido XML para agregar a la plantilla

## Valor(es) devuelto(s)

**delivery** devuelve el documento de envío creado

## Funciones

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sí
