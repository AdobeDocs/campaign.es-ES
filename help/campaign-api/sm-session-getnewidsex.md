# GetNewIdsEx

Obtener una lista de identificadores únicos de la base de datos, con un nombre de secuencia.

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Parámetros

**count** Número de identificadores que este método debe devolver

**sequence** Nombre de la secuencia que se incrementará

## Valor(es) devuelto(s)

**idList** Lista de identificadores separados por comas
