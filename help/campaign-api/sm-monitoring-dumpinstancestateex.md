# DumpInstanceStateEx

Devolver estados de procesos de servidor

```text
XML monitoring = DumpInstanceStateEx ( String mask, Boolean includeDead, Boolean noDatabaseCheck, Number criticalLevel )
```

## Parámetros

**máscara** máscara para que las instancias se consideren

**includeDead** Agregar lista de procesos inactivos

**noDatabaseCheck** no comprueba las alertas de los objetos de base de datos

**criticalLevel** filtra la gravedad de las alertas devueltas

## Valor(es) devuelto(s)

**supervisión**
