# GetAccessInfo

Devuelve las propiedades heredadas del modo anónimo.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Parámetros

**categoryId** Identificador de categoría

## Valor(es) devuelto(s)

**anonymous** Especifica si las ofertas de categoría son anónimas

**parentAnonymous** Especifica si las ofertas de categoría principal son anónimas
