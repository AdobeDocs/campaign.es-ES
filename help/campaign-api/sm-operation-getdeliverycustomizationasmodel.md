# GetDeliveryCustomizationAsModel

Copie las plantillas de campo de personalización seleccionadas.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## Parámetros

**selection** elemento que contiene los identificadores de plantilla seleccionados

**parentIn** elemento que contiene las personalizaciones existentes

## Valor(es) devuelto(s)

**parentOut** Devuelve el elemento con las nuevas plantillas agregadas
