# addHeader

Agrega un encabezado HTTP adicional a la respuesta.

```text
addHeader (nom, valeur)
```

## Parámetros

**nom** Nombre del encabezado que se va a agregar.

**valor** del valor del encabezado agregado.

## Valor devuelto

Ninguna.

## Funciones

**Método de clase:** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en:**

* JSSP
* WebApp
