# HttpServletResponse (Clase)

Representa la respuesta de un servlet devuelto a un cliente.

Solo hay una instancia de esta clase accesible por la variable `response`.

## Métodos

| Método | Descripción |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | Cambia el tipo de documento de la respuesta. |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | Devuelve una redirección temporal a otra dirección URL. |
| [addCookie](m-httpservletresponse-addcookie.md) | Agrega una cookie a la respuesta. |
| [addHeader](m-httpservletresponse-addheader.md) | Agrega un encabezado HTTP adicional a la respuesta. |
| [sendError](m-httpservletresponse-senderror.md) | Devuelve una respuesta de error utilizando el código de error pasado como parámetro. |

## Funciones
