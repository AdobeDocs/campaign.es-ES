# GetMirrorURL

Obtiene la dirección URL de una página espejo HTML.

```text
String url = GetMirrorURL ( Number deliveryId, String message )
```

## Parámetros

**deliveryId** Identificador de envío

**message** ID de mensaje

## Valor(es) devuelto(s)

**url** URL de página espejo
