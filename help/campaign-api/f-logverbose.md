# logVerbose

Agrega un mensaje de información al registro de la instancia de flujo de trabajo. Este mensaje solo está visible en el modo &quot;detallado&quot;.

```text
logVerbose (message)
```

## Parámetros

**message** Mensaje que se agregará al registro.

## Valor devuelto

Ninguna.

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Envío del mensaje
* Regla de tipología
* Importación
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
