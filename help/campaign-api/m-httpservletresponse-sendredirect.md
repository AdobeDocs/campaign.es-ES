# sendRedirect

Devuelve una redirección temporal a otra dirección URL.

```text
sendRedirect (location)
```

## Parámetros

URL de redirección de **ubicación**.

## Valor devuelto

Ninguna.

## Funciones

**Método de clase:** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en:**

* JSSP
* WebApp
