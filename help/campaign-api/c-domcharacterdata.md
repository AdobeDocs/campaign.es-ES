# DOMCcharacterData, clase

Nodo que contiene solo texto. Puede ser un nodo de texto o un comentario.

## Métodos

| Método | Descripción |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | Extraiga una parte del texto. |
| [appendData](m-domcharacterdata-appenddata.md) | Agregue una cadena de caracteres al texto. |
| [insertData](m-domcharacterdata-insertdata.md) | Inserta una cadena de caracteres en el texto en una posición específica. |
| [deleteData](m-domcharacterdata-deletedata.md) | Eliminar una parte del texto. |
| [replaceData](m-domcharacterdata-replacedata.md) | Reemplazar una parte del texto. |

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [datos](p-domcharacterdata-data.md) | Valor de texto del nodo. |
| [length](p-domcharacterdata-length.md) | Número de caracteres del nodo. |
