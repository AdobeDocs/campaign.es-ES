# substringData

Extraiga una parte del texto.

```text
substringData (offset, count)
```

## Parámetros

**desplazamiento** Posición del primer carácter (0 para el primer carácter).

**count** número de caracteres que se van a extraer.

## Valor devuelto

Cadena de caracteres extraída.
