# NotifyValidation

Notificación de aprobación en una campaña.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Parámetros

**deliveryId** Identificador de envío

**destino** Validación de segmentación

**contenido** Aprobación de contenido

**presupuesto** aprobación de presupuesto

**extracción** Aprobación del archivo de extracción

**FCP** Aprobación de revisión

**zona protegida** Aprobación de estimación de destino

**edición** Edición de contenido

**externo** Aprobación de contenido externo

## Valor(es) devuelto(s)

Ninguna.
