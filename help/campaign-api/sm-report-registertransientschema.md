# RegisterTransientSchema

Guarda un esquema asociado a los resultados de una consulta

```text
RegisterTransientSchema ( String name, String label, String sqltable, XML query )
```

## Parámetros

**nombre** Nombre de esquema

**etiqueta** Etiqueta de esquema

**sqltable** nombre SQL de la tabla

**consulta** Definición de consulta

Ninguna.
