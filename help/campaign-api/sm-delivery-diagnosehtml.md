# Diagnosticar HTML

Inicia el diagnóstico del contenido HTML

```text
XML diagnostic = DiagnoseHTML ( String htmlContent, Number format )
```

## Parámetros

**htmlContent** contenido de HTML que se comprobará

**formato** El formato de correo

## Valor(es) devuelto(s)

**diagnóstico** devuelve el diagnóstico
