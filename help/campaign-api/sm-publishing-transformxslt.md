# TransformXSLT

Transformación de publicación basada en XSLT

```text
String result = TransformXSLT ( String source, String namespace, String format, String contentId )
```

## Parámetros

**origen** contenido de hoja de estilos XSLT

**área de nombres** utilizada para directivas xsl:import relativas

**formato** Formato de salida

**contentId** Identificador de contenido

## Valor(es) devuelto(s)

**resultado** resultado de transformación
