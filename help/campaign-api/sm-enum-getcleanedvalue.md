# GetCleanedValue

Obtenga un valor limpio.

```text
String value = GetCleanedValue ( Number enumId, String alias )
```

## Parámetros

ID de enumeración **enumId**

**alias** valor que reemplazar

## Valor(es) devuelto(s)

**value** Valor limpiado (si no se encuentra, devuelve el alias)
