# deleteData

Eliminar una parte del texto.

```text
deleteData (offset, count)
```

## Parámetros

**desplazamiento** Posición del primer carácter que se va a eliminar (0 para el primer carácter).

**count** número de caracteres que eliminar.

## Valor devuelto

Ninguna.
