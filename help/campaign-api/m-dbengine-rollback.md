# reversión

Cancela la transacción en curso en la conexión.

```text
rollback ()
```

## Parámetros

Ninguna.

## Valor devuelto

Ninguna.

## Observaciones

Se debe haber iniciado previamente una transacción con el método [begin](m-dbengine-begin.md).
