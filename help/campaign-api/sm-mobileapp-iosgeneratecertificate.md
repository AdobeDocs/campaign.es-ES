# iOSGenerateCertificate

Codifica el certificado iOS proporcionado en base64

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## Parámetros

**fileName** Nombre de archivo

UUID de aplicación **uuid**

## Valor(es) devuelto(s)

**return** La versión base64 del certificado
