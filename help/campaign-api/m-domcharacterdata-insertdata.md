# insertData

Inserta una cadena de caracteres en el texto en una posición específica.

```text
insertData (offset, arg)
```

## Parámetros

**desplazamiento** Posición de inserción (0 para el primer carácter).

**arg** cadena de caracteres para insertar.

## Valor devuelto

Ninguna.
