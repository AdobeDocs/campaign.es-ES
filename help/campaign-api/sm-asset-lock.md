# Bloquear

Bloquea el recurso del usuario actual para informar a otros usuarios de que el recurso se está modificando

```text
Lock ( String assetId )
```

## Parámetros

**assetId** Identificador de recurso.

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:asset](s-nms-asset.md)
