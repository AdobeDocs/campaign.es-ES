# GetDescriptiveAnalysisData

Ejecuta la consulta para obtener datos de análisis descriptivos.

```text
XML data = GetDescriptiveAnalysisData ( XML entity, XML context )
```

## Parámetros

**entidad** documento XML que describe el gráfico

**context** contexto XML utilizado para filtrar los datos

## Valor(es) devuelto(s)

**datos** Datos en formato XML
