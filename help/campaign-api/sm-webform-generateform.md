# GenerateForm

Genera el formulario en modo correo o web

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## Parámetros

**formName** nombre de formulario

**mailMode** Generar un formulario de tipo Correo

## Valor(es) devuelto(s)

**resultado** Resultado de la aplicación del XSL en el formulario

**Esquema:** [nms:webForm](s-nms-webform.md)
