# GenerateLinkDimension

Generar una dimensión basada en un vínculo.

```text
XML result = GenerateLinkDimension ( XML dimension, XML linklevels )
```

## Parámetros

**dimensión** Dimension para ingresar

**linklevels** niveles disponibles

## Valor(es) devuelto(s)

**result** ingresó una dimensión
