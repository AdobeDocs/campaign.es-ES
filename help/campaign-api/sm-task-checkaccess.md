# CheckAccess

Comprueba si el operador actual puede acceder a la tarea.

```text
Boolean result = CheckAccess ( XML taskEntity )
```

## Parámetros

**taskEntity** Entidad de tarea

## Valor(es) devuelto(s)

**resultado** Valor devuelto del método (sí/no)

**Esquema:** [nms:task](s-nms-task.md)
