# Entidad (clase)

Representa una entidad de la base de datos para un esquema determinado.

No se puede crear una instancia de este objeto directamente. Se deben utilizar los métodos create(), get() o load().

## Métodos

| Método | Descripción |
| --- | --- |
| [guardar](m-entity-save.md) | Guarda una entidad en la base de datos. |
