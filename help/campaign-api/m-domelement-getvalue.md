# getValue

Devuelve el valor del nodo al que hace referencia el XPath dado.

```text
getValue (xpath)
```

## Parámetros

Ruta de acceso **xpath**.

## Valor devuelto

Valor de texto del nodo referenciado.

## Observaciones

La sintaxis de XPath solo acepta un subconjunto de lenguaje XPath. Se genera una excepción si la ruta está mal formada.
