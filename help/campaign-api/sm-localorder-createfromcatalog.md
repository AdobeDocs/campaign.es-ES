# CreateFromCatalog

Cree un pedido a partir de un paquete.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## Parámetros

ID de paquete **catalogId**.

**orgUnitId** ID de entidad local. (opcional)

## Valor(es) devuelto(s)

**localOrder** Devuelve el pedido creado.

## Funciones

**Esquema:** [nms:localOrder](s-nms-localorder.md)

Sí
