# UpdateCachedDelivery

Se debe llamar cada vez que se modifica el envío en la memoria para que otros subprocesos tengan acceso a una versión actualizada (método privado).

```text
delivery.UpdateCachedDelivery ()
```

## Parámetros

Ninguna.

## Valor(es) devuelto(s)

Ninguna.

No

No
