# lookupNamespaceURI

Se ha buscado el URI del área de nombres vinculada al prefijo dado.

```text
lookupNamespaceURI (prefix)
```

## Parámetros

Prefijo **prefix**.

## Valor devuelto

URI del área de nombres o cadena vacía si no se encuentra.
