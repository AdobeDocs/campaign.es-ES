# fileSize

Devuelve el tamaño de un archivo en bytes.

```text
fileSize (filename)
```

## Parámetros

**nombre de archivo** El nombre completo del archivo.

## Valor devuelto

Devuelve el tamaño del archivo o -1 si se produjo un error (por ejemplo, si no se encontró el archivo).

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
