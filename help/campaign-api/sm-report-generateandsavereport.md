# GenerateAndSaveReport

Genera un informe desde el servidor y lo guarda en la base de datos

```text
XML result = GenerateAndSaveReport ( String reportName, XML context )
```

## Parámetros

**reportName** Nombre interno del informe

Configuración del informe **context**

## Valor(es) devuelto(s)

**resultado** Identificador único y fecha de registro
