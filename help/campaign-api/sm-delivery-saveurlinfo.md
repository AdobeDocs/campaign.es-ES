# SaveUrlInfo

Guarde las direcciones URL de este envío como plantillas de URL.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Parámetros

**insUrlList**: lista de direcciones URL nuevas (no asociadas a una plantilla de dirección URL)

**updUrlList** Lista de plantillas de URL a actualizar

## Valor(es) devuelto(s)

Ninguna.
