# ComputeUrl

Genera la dirección URL para acceder a esta pURL

```text
[ String url, String exampleUrl ] = ComputeUrl ( XML purl )
```

## Parámetros

**purl** purl actual.

## Valor(es) devuelto(s)

**url** URL (técnica)

**exampleUrl** URL que contiene datos ficticios (para mostrar)

**Esquema:** [nms:purl](s-nms-purl.md)

Sí
