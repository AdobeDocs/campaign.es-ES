# mkdir

Crea un directorio con la ruta del objeto [File](c-file.md) actual.

```text
mkdir ()
```

## Parámetros

Ninguna.

## Valor devuelto

Ninguna.

## Observaciones

También crea directorios intermedios si es necesario. Se genera una excepción en caso de error.
