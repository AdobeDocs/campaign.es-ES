# CreateTrackingInstance

Crear o configurar una instancia de seguimiento en un servidor de redirección

```text
CreateTrackingInstance ( String internalPwd, String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## Parámetros

**internalPwd** contraseña interna

**serverUrl** URL externa del servidor de seguimiento

**secureServerUrl** URL segura externa del servidor de seguimiento

**serverUrlList** URL internas de los servidores de seguimiento

**instanceName** Nombre de la instancia que se va a crear

**cryptedPassword** Contraseña cifrada

**host** máscaras DNS asociadas a la instancia

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:trackingUrl](s-nms-trackingurl.md)

**Estático:**

Sí
