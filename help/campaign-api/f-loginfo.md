# logInfo

Agrega un mensaje de información al registro de la instancia de flujo de trabajo.

```text
logInfo (message)
```

## Parámetros

**message** Mensaje que se agregará al registro.

## Valor devuelto

Ninguna.

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Envío del mensaje
* Regla de tipología
* Importación
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
