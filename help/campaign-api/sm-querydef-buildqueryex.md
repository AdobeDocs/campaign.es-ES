# BuildQueryEx

Devuelve la consulta generada y la cadena de formato

```text
[ String sql, String format ] = queryDef.BuildQueryEx () const
```

## Parámetros

Ninguna.

## Valor(es) devuelto(s)

**sql** Consulta de salida

**format** Cadena de formato, compatible con la función JavaScript sqlSelect().

**Esquema:** [xtk:queryDef](s-xtk-querydef.md)

**Estático:**

No

Sí
