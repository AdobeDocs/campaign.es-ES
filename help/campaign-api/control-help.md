# Ayuda

Mostrar un texto y una imagen.

![Control de ayuda](assets/help.67cf3e33.png)

## Propiedades

**img - cadena** Imagen asociada.

**etiqueta - cadena** Texto para mostrar.

## Observaciones

Ejemplo:

```xml
      <static type="help" label="Please enter your name here."/>

<static type="help">Please enter your name here.</static>
```
