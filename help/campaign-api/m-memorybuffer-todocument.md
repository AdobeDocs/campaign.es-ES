# toDocument

Devuelve un documento XML a partir del contenido de texto de este búfer.

```text
toDocument ( [codePage ])
```

## Parámetros

**codePage** Un entero que codifica la página de caracteres usada. De forma predeterminada, MemoryBuffer.CODEPAGE\_UTF8.

## Valor devuelto

Un objeto de tipo [DOMDocument](c-domdocument.md).
