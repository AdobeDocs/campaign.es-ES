# packageStatus

Devuelve un número que indica el estado del paquete.

```text
packageStatus
```

## Observaciones

El estado del paquete es el siguiente:

* Schema.PACKAGE\_STATUS\_DEFAULT
* Schema.PACKAGE\_STATUS\_NEVER
* Schema.PACKAGE\_STATUS\_ALWAYS
* Schema.PACKAGE\_STATUS\_PRECREATE
