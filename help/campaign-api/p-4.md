# Excepciones de JavaScript

De forma predeterminada, cuando se produce un error, se interrumpe la secuencia de comandos que se está ejecutando. Sin embargo, la versión 4.05 y posteriores sí permiten capturar errores y manejarlos para continuar procesando la secuencia de comandos.

Las excepciones generadas por Adobe Campaign son códigos de error (de tipo `Number`).

## Ejemplo

Este ejemplo intenta recuperar una página web de una dirección no válida y genera una excepción de la función [getUrl()](f-geturl.md).

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
