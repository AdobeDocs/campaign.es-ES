# WebPostupload

Finalice el almacenamiento del recurso después de la carga (desde una página web) en el servidor en función del tipo de almacenamiento utilizado. Recupera la página de códigos y el tipo de contenido.

```text
fileRes.WebPostUpload ( XML params )
```

## Parámetros

**params** Para el almacenamiento de tipo &quot;workspace&quot;: @formerFileName contiene el nombre anterior en el área de trabajo. Si desea guardar la entidad inmediatamente: @immediateSave debe configurarse como &quot;true&quot;

## Valor(es) devuelto(s)

Ninguna.
