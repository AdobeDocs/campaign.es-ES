# setEnv

>[!WARNING]
>
>Esta función está disponible para un entorno local.

>[!NOTE]
>
>Puede deshabilitar esta función pasando la opción **XtkSecurity\_Disable\_GetSetEnv** a **true**.

Establezca el valor de una variable de entorno.

```text
setEnv (name, value)
```

## Parámetros

**nombre** Nombre de la variable de entorno.

**Valor** Valor nuevo para la variable de entorno.

## Valor devuelto

El nuevo valor de la variable.

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Envío del mensaje
* Regla de tipología
* Importación
