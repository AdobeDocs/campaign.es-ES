# getFirstElement

Devuelve el primer elemento secundario al comprobar los criterios determinados.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Parámetros

**tagName** Nombre del elemento buscado.

**attrName** Nombre de un atributo que debe comprobar un valor determinado.

Valor de atributo **attrValue**.

## Valor devuelto

Primer elemento que verifica los criterios dados o nulo.
