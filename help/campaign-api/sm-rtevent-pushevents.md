# PushEvents

Insertar una colección de eventos.

```text
XML ids = PushEvents ( XML eventCollection )
```

## Parámetros

**eventCollection**: colección de eventos.

## Valor(es) devuelto(s)

**ids** colección que contiene la combinación de los identificadores externos e internos utilizados durante la inserción.
