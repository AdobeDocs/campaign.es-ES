# DuplicateTo

Duplica un nuevo documento desde un documento de origen en una carpeta determinada

```text
session.DuplicateTo ( String pk, String folder )
```

## Parámetros

**pk** clave principal del documento de origen

**carpeta** Clave principal de la carpeta de destino

## Valor(es) devuelto(s)

Ninguna.
