# insertBefore

Inserte un nodo antes de una posición específica.

```text
insertBefore (newChild, refChild)
```

## Parámetros

**nuevoNodo** secundario para insertar.

**refChild** Nodo secundario que debe ir después del nodo que se va a insertar.

## Valor devuelto

Nodo insertado.

## Funciones

**Método de clase:** [DOMNode](c-domnode.md)

* Administración de contenido
* Propiedades de envío
