# sueño

Suspende la secuencia de comandos durante un tiempo especificado.

```text
sleep (delay)
```

## Parámetros

**delay** tiempo en milisegundos.

## Valor devuelto

Ninguna.

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
