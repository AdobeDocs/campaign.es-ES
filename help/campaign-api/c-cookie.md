# Cookie (Clase)

Representa una cookie intercambiada por el servlet y el explorador web.

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [nombre](p-cookie-name.md) | Nombre de la cookie. |
| [comentario](p-cookie-comment.md) | Comentario que describe la función de la cookie, nulo si no está definido. |
| [dominio](p-cookie-domain.md) | Nombre de dominio de la cookie. |
| [maxAge](p-cookie-maxage.md) | Duración de la cookie en segundos. |
| [ruta](p-cookie-path.md) | Ruta basada en la cual el explorador web reenvía la cookie. |
| [seguro](p-cookie-secure.md) | true si la cookie solo se puede reenviar mediante un protocolo seguro. |
| [valor](p-cookie-value.md) | Valor de cookie. |
| [versión](p-cookie-version.md) | Versión del protocolo con el que es compatible la cookie. |

## Funciones

**Disponible en:**

* JSSP
* WebApp
