# parámetros

Devuelve los parámetros de consulta.

```text
parameters
```

## Observaciones

La propiedad parameters devuelve un objeto con propiedades que coinciden con un parámetro de la consulta. Ejemplo:

```javascript
var parameters = request.parameters
for(var name in parameters)
{
var value = parameters[name]
document.write(name + " : " + value + "<br>")
}
```
