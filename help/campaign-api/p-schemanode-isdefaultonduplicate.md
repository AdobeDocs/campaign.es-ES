# isDefaultOnDuplicate

Devuelve un valor booleano. Si el valor añadido es vario, durante la anulación de duplicación de registros, el valor predeterminado (definido en defaultValue) se vuelve a aplicar automáticamente durante la grabación.

```text
isDefaultOnDuplicate
```
