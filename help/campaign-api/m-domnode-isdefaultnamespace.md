# isDefaultNamespace

Comprueba si el área de nombres determinada es la predeterminada.

```text
isDefaultNamespace (namespaceURI)
```

## Parámetros

**namespaceURI**: URI de espacio de nombres.

## Valor devuelto

true si namespaceURI es el área de nombres predeterminada; en caso contrario, false.
