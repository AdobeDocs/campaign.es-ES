# CompleteTaskOperation

Completa una tarea creada en el contexto de una campaña.

```text
XML taskOut = CompleteTaskOperation ( XML taskIn, XML parameter )
```

## Parámetros

**taskIn** tarea entrante

**parámetro** Configuración del contexto de campaña

## Valor(es) devuelto(s)

**taskOut** Actualizar tarea
