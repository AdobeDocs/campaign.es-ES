# PushTrackingInfo

Permite cargar en el servidor de seguimiento remoto toda la información relativa a un envío.

```text
PushTrackingInfo ( String instance, String dbId, String jobId, XML document )
```

## Parámetros

**instancia** Nombre de instancia

**dbId** Identificador de base de datos para el cliente que realiza una entrega

**jobId**: id. de envío.

**documento** que contiene la información de seguimiento de este envío

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:remoteTracking](s-nms-remotetracking.md)

**Estático:**

Sí
