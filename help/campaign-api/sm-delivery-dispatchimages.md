# DispatchImages

Indica al servidor de aplicaciones que envíe las imágenes al servidor intermediario.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Parámetros

**imágenes** Lista de imágenes para cargar en el servidor intermediario.

**providerId** Identificador del enrutador de envío.

**providerName** Nombre del enrutador de envío.

## Valor(es) devuelto(s)

Ninguna.
