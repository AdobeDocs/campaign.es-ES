# BuildTableList

Obtiene una lista de nombres de tabla.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Parámetros

**dataSource** ID del origen de datos

**tablePattern** Máscara para el nombre de tabla

## Valor(es) devuelto(s)

**tableList** listas de tablas existentes
