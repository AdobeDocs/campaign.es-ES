# CreateInstanceFromModel

Muestra una instancia de un objeto a través de una plantilla

```text
Number output = CreateInstanceFromModel ( String schema, Number modelId, XML diff )
```

## Parámetros

**esquema** esquema de instancia

**modelId** ID de la plantilla

**diff** parche XML para aplicar a la plantilla

## Valor(es) devuelto(s)

**salida** ID de la instancia creada
