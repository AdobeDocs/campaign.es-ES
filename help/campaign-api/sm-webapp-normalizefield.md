# NormalizeField

```text
NormalizeField ( XML selectedWebApp, XML archivedField, String newSQLName, String tableName, String schemaId, Boolean rename )
```

## Parámetros

**selectedWebApp**: lista de encuestas que pueden contener el campo que se va a normalizar.

**archivedField** Información sobre el campo a normalizar.

**newSQLName** Nuevo nombre SQL de este campo.

**tableName** Nombre de la tabla que contendrá el nuevo campo SQL.

**schemaId** Identificador de esquema (vista) donde se agrega una referencia que pertenece al nuevo campo (opcional).

**cambiar el nombre** También cambie el nombre de los campos estandarizados anteriormente.

## Valor(es) devuelto(s)

Ninguna.
