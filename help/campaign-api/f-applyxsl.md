# applyXsl

Transforma un documento XML mediante una hoja de estilos XSL.

```text
applyXsl (xslEntity, xml)
```

## Parámetros

**xslEntity**: nombre de la hoja de estilos XSL almacenada en la base de datos.

**xml** Documento XML o cadena de caracteres que contiene el documento XML que se va a transformar.

## Valor devuelto

Documento XML en forma de cadena de caracteres después de la transformación.
