# CreateTrackingInstanceShell

Crear o configurar una instancia de seguimiento en un servidor de redirección

```text
CreateTrackingInstanceShell ( String internalPwd, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## Parámetros

**internalPwd** contraseña interna

**serverUrlList** URL internas de los servidores de seguimiento

**instanceName** Nombre de la instancia que se va a crear

**cryptedPassword** Contraseña cifrada

**host** máscaras DNS asociadas a la instancia

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:trackingUrl](s-nms-trackingurl.md)

**Estático:**

Sí
