# PathEdit

Control para seleccionar un campo.

## Propiedades

**backColor - string** Color de fondo (btnshadow, blanco).

**border - string** Cambia el estilo del esquema de control (solid, double, inset, begin, none).

**tamaño de fuente - entero** Cambia el tamaño de fuente.

**hideCalculated - boolean**: oculta los campos calculados.

**hideMappedAsXml: booleano** oculta campos XML.

**etiqueta - cadena** Etiqueta asociada.

**nolabel - booleano**: oculta la etiqueta asociada.

**noTransaction - boolean** Deshabilita el modo transaccional.

**readOnly - boolean** fuerza al control a ser de solo lectura.

**obligatorio - booleano** El campo es obligatorio.

**useLink11Path - boolean** Muestra vínculos 1:1.

**useTablePath - booleano** Muestra tablas.

**useUnboundPath - booleano** Muestra colecciones.

**xpath - string** Campo que se va a editar.

**xpathBaseType - xpath** Ruta para almacenar el tipo del campo seleccionado.

**xpathDataPolicy - xpath** Ruta para almacenar la propiedad dataPolicy del campo seleccionado.

**xpathEnum - xpath** Ruta para almacenar la enumeración del sistema del campo seleccionado.

**xpathLabel: cadena** Ruta para almacenar la etiqueta del campo seleccionado.

**xpathSchema - cadena** Ruta de esquema.

**xpathSchemaMd5 - xpath** Ruta para almacenar el MD5 del esquema.

**xpathStartPath - string** Ruta de startPath (solo se usa si xpathSchema está definido).

**xpathUnbound: ruta de acceso xpath** para almacenar la propiedad independiente del campo seleccionado.

**xpathUserEnum - xpath** Ruta para almacenar la enumeración gratuita del campo seleccionado.

**xpathType - xpath** Ruta para almacenar el control predeterminado del campo seleccionado.

**zoom - booleano** Muestra el botón de edición.
