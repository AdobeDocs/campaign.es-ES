# Muestras

## Métodos estáticos

El acceso a los métodos de SOAP se logra invocando un método en el objeto que representa el esquema. Los esquemas son objetos globales NLWS. El ejemplo siguiente invoca el método estático [PostEvent](sm-workflow-postevent.md) del esquema [xtk:workflow](s-xtk-workflow.md).

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## Métodos no estáticos

Para usar los métodos SOAP no estáticos, primero debe recuperar una entidad usando los métodos [load](f-load.md) o [create](f-create.md) en los esquemas correspondientes. El ejemplo siguiente invoca el método [ExecuteQuery](sm-querydef-executequery.md) del esquema [xtk:queryDef](s-xtk-querydef.md).

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## Limitaciones

No se pueden usar ciertas llamadas no estáticas porque el objeto que se está cargando (\*\*) carece de datos. Este es el caso, por ejemplo, de ciertas llamadas en [nms:delivery](s-nms-delivery.md).
