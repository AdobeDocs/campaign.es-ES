# HtmlToText

Convierte el contenido del HTML en texto sin formato

```text
String textContent = HtmlToText ( String htmlContent )
```

## Parámetros

**htmlContent** contenido de HTML para convertir

## Valor(es) devuelto(s)

**textContent** devuelve texto convertido
