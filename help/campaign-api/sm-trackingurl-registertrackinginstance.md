# RegisterTrackingInstance

Aprueba una instancia de seguimiento en un servidor de redirección (estableciendo el identificador de base de datos).

```text
RegisterTrackingInstance ( String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword )
```

## Parámetros

**serverUrl** URL externa del servidor de seguimiento

**secureServerUrl** URL segura externa del servidor de seguimiento

**serverUrlList** URL internas de los servidores de seguimiento

**instanceName** Nombre de la instancia que se va a aprobar

**cryptedPassword** Contraseña cifrada

## Valor(es) devuelto(s)

Ninguna.

## Funciones

**Esquema:** [nms:trackingUrl](s-nms-trackingurl.md)

**Estático:**

Sí
