# fileRename

Cambia el nombre de un archivo.

Si no se especifica la codificación de caracteres, se utiliza el servidor predeterminado.

```text
fileRename (oldname, newname)
```

## Parámetros

**oldname**: nombre completo del archivo cuyo nombre se va a cambiar.

**newname**: el nuevo nombre del archivo.

## Valor devuelto

Ninguna.
