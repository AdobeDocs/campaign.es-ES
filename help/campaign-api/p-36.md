# Página Directiva

Incluye una biblioteca de funciones o cadenas.

## Sintaxis

&lt;%@ page import=&quot;lib1, ...&quot; %> &lt;%@ page stringGroup=&quot;groupName&quot; %>

## Descripción

La importación de una biblioteca de cadenas expone un objeto JavaScript global cuyo nombre empieza por sg\_ seguido del nombre de la biblioteca cuyos caracteres especiales se han reemplazado por &#39;\_&#39;. Por ejemplo, si se incluye nms:campaign, se creará la variable sg\_nms\_campaign.

## Ejemplo

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
