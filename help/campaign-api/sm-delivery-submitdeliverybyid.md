# SubmitDeliveryById

Crear y enviar un envío desde un escenario (identificado por su nombre interno).

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## Parámetros

**scenarioId** Identificador de plantilla

**contenido** contenido XML para agregar a la plantilla

## Valor(es) devuelto(s)

**deliveryId** contenido XML para agregar a la plantilla

Sí
