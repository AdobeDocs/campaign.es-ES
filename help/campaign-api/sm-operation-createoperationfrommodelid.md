# CreateOperationFromModelId

Cree una campaña a partir de una plantilla de campaña.

```text
Number operationId = CreateOperationFromModelId ( Number modelId, XML operationPlanning )
```

## Parámetros

**modelId** identificador de plantilla de campaña

Programación de la campaña **operationPlanning**

## Valor(es) devuelto(s)

**operationId**: identificador de la instancia creada

**Esquema:** [nms:operation](s-nms-operation.md)
