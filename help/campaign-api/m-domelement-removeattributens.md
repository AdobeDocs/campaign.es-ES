# removeAttributeNS

Eliminar un atributo.

```text
removeAttributeNS (namespaceURI, localName)
```

## Parámetros

URI **namespaceURI** del atributo namespace.

Nombre de atributo **localName**.

## Valor devuelto

Ninguna.

## Observaciones

El método no tiene ningún efecto si el elemento no tiene ningún atributo con este nombre.
