# getElementById

Devuelve el elemento con el identificador especificado.

```text
getElementById (elementId)
```

## Parámetros

**elementId**: identificador de elemento buscado. Una cadena de caracteres con distinción significativa entre mayúsculas y minúsculas.

## Valor devuelto

El elemento o nulo si el documento no contiene ningún elemento con un ID específico.
