# atributos

Devuelve una tabla que contiene la lista de atributos si el nodo es un elemento; en caso contrario, es nulo.

```text
attributes
```

## Observaciones

Esta propiedad crea una nueva tabla para cada acceso. Por lo tanto, es mejor mantener la tabla en una variable local en lugar de acceder a la propiedad varias veces.
