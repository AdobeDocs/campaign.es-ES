# createTextNode

Crea un nuevo nodo de texto.

```text
createTextNode (data)
```

## Parámetros

**datos** Cadena de caracteres para insertar en el nodo de texto.

## Valor devuelto

Se ha creado el nodo de tipo [DOMCharacterData](c-domcharacterdata.md).
