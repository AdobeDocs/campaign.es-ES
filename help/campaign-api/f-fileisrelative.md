# fileIsRelative

Especifica si un nombre de archivo es o no un nombre relativo.

```text
fileIsRelative (fileName)
```

## Parámetros

**fileName** Nombre de archivo.

## Valor devuelto

El valor verdadero del nombre de archivo es relativo.

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
