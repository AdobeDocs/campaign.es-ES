# reverseLink

Si el elemento es un vínculo, devuelve un objeto [SchemaNode](c-schemanode.md) que representa un vínculo inverso (a través del esquema de destino). Si no es así, la propiedad no está definida.

```text
reverseLink
```

**Propiedad de la clase:** [NodoEsquema](c-schemanode.md)
