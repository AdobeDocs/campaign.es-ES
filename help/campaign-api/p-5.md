# Uso de fechas

En este capítulo se detallan las funciones que se utilizan para manipular fechas en los programas de JavaScript ejecutados en el servidor (flujo de trabajo, JSSP, etc.).

## Fechas y zonas horarias

En JavaScript, las fechas se almacenan según UTC. Esto significa que solo debe preocuparse por los husos horarios para la construcción de fechas o la conversión en cadenas de texto para la visualización interna o el almacenamiento. Para la conversión de fechas, hay dos categorías de funciones:

* las funciones de la biblioteca JavaScript (date.toString(), date.toLocaleString(), date.getHours(), ...),
* las funciones de la plataforma Adobe Campaign ( [formatDate(date, format)](f-formatdate.md) ).

Por convención, la primera utiliza la zona horaria de la máquina, mientras que la última utiliza una zona horaria según el contexto: normalmente la del operador actual, pero este comportamiento se puede modificar para exportaciones o flujos de trabajo, por ejemplo.

## Obtener fecha actual

Existen dos formas de obtener la fecha actual en JavaScript:

* new Date() crea un nuevo objeto Date inicializado con la fecha actual. La fecha coincide con la hora de la máquina en la que se ejecuta el script.
* [getCurrentDate()](f-getcurrentdate.md) devuelve la fecha actual en función de la hora del servidor de base de datos.

La función [getCurrentDate()](f-getcurrentdate.md) es preferible a la primera solución, especialmente cuando la fecha se va a comparar con otras fechas de la base de datos o se va a escribir en ella. Este método reduce el riesgo de discrepancias (de hasta varios minutos) vinculadas a diferencias de tiempo entre el servidor de aplicaciones y el servidor de la base de datos

## Visualización de la fecha

La conversión de una fecha en una cadena de caracteres con fines de visualización usa la función [formatDate](f-formatdate.md).

## Convertir una fecha de un documento XML

Las fechas almacenadas en un documento XML procedente de la base de datos de Adobe Campaign están en forma de texto: se pueden convertir mediante la función [parseTimeStamp](f-parsetimestamp.md). Esto suele afectar a los documentos XML devueltos por el método [ExecuteQuery](sm-querydef-executequery.md). Ejemplo :

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## Insertar una fecha en un documento XML

Ya sea para escribir una fecha en un atributo XML, para guardar un documento (método [Write](sm-session-write.md)) o para insertar una fecha literal en la expresión de una consulta, la fecha deberá convertirse al formato ISO8601. Hay un método en la biblioteca de funciones xtk:shared/nl.js para convertir una fecha a este formato: el método NL.XTK.formatDateTime(date). La biblioteca se puede cargar mediante la función loadLibrary:

```javascript
loadLibrary("xtk:shared/nl.js")
```

o usar la directiva de página en el caso de una página JavaScript dinámica (JSSP):

```xml
<%@ page import="xtk:shared/nl.js" %>
```

Advertencia: no se puede utilizar loadLibrary para todos los scripts. Por ejemplo, no se puede cambiar una biblioteca de funciones de JavaScript en un script de personalización de correo electrónico. Ejemplo : Este ejemplo muestra la construcción de una consulta utilizando una fecha literal.

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
