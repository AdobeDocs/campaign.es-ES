# RegisterExternalInstance

Aprueba una instancia de seguimiento en un servidor de retransmisión para los servidores de redirección (estableciendo el identificador de base de datos).

```text
RegisterExternalInstance ( String login, String instanceName, String dbId, Boolean saveParams )
```

## Parámetros

**iniciar sesión** Inicio de sesión de acceso al servidor de retransmisión

**instanceName** Nombre de la instancia que se va a aprobar

**dbId** Identificador de base de datos para el cliente que realiza una entrega

**saveParams** Guardar opciones si se realiza correctamente

## Valor(es) devuelto(s)

Ninguna.
