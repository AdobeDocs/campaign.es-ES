# setFile

> Advertencia:
>
> El acceso a través de las API de archivo está limitado a **var**, **sftp** y a las carpetas temporales de Adobe Campaign.

Define el modo de transferencia y el archivo de recepción.

```text
setFile (filename)
```

## Parámetros

**nombre de archivo** Nombre del archivo local.

## Valor devuelto

Ninguna.

## Funciones

**Método de clase:** [FTP](c-ftp.md)

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
