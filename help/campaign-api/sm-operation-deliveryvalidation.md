Aprobación de un envío en una campaña.

```text

```

## Parámetros

**deliveryId** Identificador de envío

**tipo** Tipo de aprobación (segmentación=0, contenido=1, presupuesto=2, extracción=3)

**rechazado** rechazar

**comentario** comentario
