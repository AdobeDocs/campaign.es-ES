# FillSteps

Cree automáticamente límites para un número igual de grupos.

```text
XML samplingSteps = FillSteps ( String schema, String expr, Number classCount )
```

## Parámetros

**esquema** Esquema raíz del análisis

**expr** expresión de Source

**classCount** Número de grupos que se van a generar

## Valor(es) devuelto(s)

**samplingSteps** Lista de pasos

## Funciones

**Esquema:** [xtk:abstractForm](s-xtk-abstractform.md)

Sí
