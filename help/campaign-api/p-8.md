# Protección de datos: funciones de escape

Adobe Campaign proporciona un conjunto de funciones que proporcionan protección contra los ataques más frecuentes: inyecciones SQL, ataques XSS, etc.

Las funciones de escape deben utilizarse bajo la supervisión de los operadores y Adobe no puede ser considerado responsable del mal uso o de la falta de uso de estas funciones durante el desarrollo.

La regla general es la siguiente:

**Todos los parámetros deben ser de escape. La función utilizada para el escape depende del formato de destino de los datos.**

## Escape simplificado

En los JSSP, Adobe Campaign proporciona la etiqueta &quot;&lt;%=&quot; que permite escapar una variable utilizada en una entidad XML o HTML generada. Este método es más práctico y equivale a NL.XML.escape(). El siguiente ejemplo ilustra el uso de la etiqueta para omitir un parámetro:

```xml
<li>
<%= strRecipientList %>
</li>
```

## Escape avanzado:

Adobe Campaign proporciona 4 funciones que le permiten aplicar secuencias de escape a un parámetro según el formato de destino. Para acceder a estas funciones de escape, asigne un nombre a los siguientes archivos, respectivamente:

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data) para aplicar un escape a una variable utilizada en una entidad XML o HTML generada. Esta función es el equivalente de la sintaxis &#39;&lt;%=&#39;. Esta función se define en el paquete NL.XML.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) para aplicar un escape a un parámetro que se puede utilizar en una consulta SQL. Esta función coloca automáticamente la expresión entre comillas simples. Esta función se define en el paquete NL.SQL.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) para omitir un parámetro que se va a utilizar en una expresión XTK. Esta función se define en el paquete NL.XTK.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data) para omitir una variable utilizada en javascript ejecutada por el cliente. Esta función se define en el paquete NL.JS.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```
