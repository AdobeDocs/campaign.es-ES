# AddInstance

> Advertencia: Esta función está disponible para un entorno local.

Declara una nueva instancia en el servidor

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## Parámetros

**instanceName** Nombre de la instancia que se va a crear

**hosts** máscaras DNS asociadas a la instancia

**lang** idioma de instancia

## Valor(es) devuelto(s)

Ninguna.
