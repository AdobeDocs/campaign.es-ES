# BuildOutputSchema

Genera un esquema a partir de un esquema de origen.

```text
XML schema = BuildOutputSchema ( XML source, Boolean saveEntity )
```

## Parámetros

**origen** esquema de Source

**saveEntity** Guardar esquema después de la generación

## Valor(es) devuelto(s)

**esquema** esquema generado

**Esquema:** [xtk:builder](s-xtk-builder.md)
