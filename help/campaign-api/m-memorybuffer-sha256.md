# sha256

Calcula la firma SHA-2 de 256 bits del contenido MemoryBuffer.

```text
sha256 ()
```

## Parámetros

Ninguna.

## Valor devuelto

Una cadena de caracteres que es la representación hexadecimal de la firma SHA-2 de 256 bits.
