# Priorizar Logs

Priorizar el registro de envío para una lista de envíos

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Parámetros

**id** Identificador único de priorización

**envíos** lista de envíos a tener en cuenta

**logTable** tabla que contiene todos los mensajes de registro

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:delivery](s-nms-delivery.md)
