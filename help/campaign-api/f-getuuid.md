# getUUID

Generación de un identificador único (ID único universal).

```text
getUUID ()
```

## Parámetros

Ninguna.

## Valor devuelto

Cadena de caracteres que contiene un identificador único de tipo &quot;550E8400-E29B-41D4-A716-446655440000&quot;.

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Regla de tipología
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
