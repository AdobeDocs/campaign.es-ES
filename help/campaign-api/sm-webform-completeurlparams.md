# CompleteURLParams

Completar la URL correcta

```text
String result = CompleteURLParams ( String formName, String xpathParams, XML recipient )
```

## Parámetros

**formName** nombre de formulario

**xpathParams** Lista separada por comas de XPath que se van a devolver

**destinatario** Datos del destinatario

## Valor(es) devuelto(s)

**result** Devuelve parámetros para la dirección URL
