# dataTransfer

Scripts de transferencia de datos (importar/exportar)

## Métodos

| Método | Descripción |
| --- | --- |
| [Detección automática](sm-datatransfer-autodetect.md) | Inicia una detección automática y devuelve las primeras líneas del archivo |
| [Limpieza](sm-datatransfer-cleanup.md) | Purgar historia de la instancia ejecutada |
| [Vista previa de exportación](sm-datatransfer-exportpreview.md) | Calcular la vista previa de la columna del archivo de salida para las primeras líneas de la consulta |
| [GetFilesToDownload](sm-datatransfer-getfilestodownload.md) | Devuelve la lista de archivos utilizados por esta transferencia y encontrados en el servidor |
| [RejectExport](sm-datatransfer-rejectexport.md) | Inicia la exportación de los rechazos |
| [Start](sm-datatransfer-start.md) | Inicia la transferencia de datos |
| [TestCalcField](sm-datatransfer-testcalcfield.md) | Pruebe el campo calculado utilizando las líneas de ejemplo almacenadas en el script. |

## Métodos genéricos

| Método | Descripción |

| [crear](f-create.md) | Crea una nueva entidad correspondiente a un esquema determinado. |
| [cargar](f-load.md) | Carga y devuelve una entidad correspondiente a un esquema y una clave determinados. |
| [guardar](m-entity-save.md) | Guarda una entidad en la base de datos. |
