# informe

Define todos los parámetros del informe

## Métodos

| Método | Descripción |
| --- | --- |
| [DictionaryCheck](sm-report-dictionarycheck.md) | Buscar cadenas para traducir en una aplicación web. |
| [DisplayDescriptiveAnalysis](sm-report-displaydescriptiveanalysis.md) | Generación de un análisis descriptivo. |
| [DisplayDescriptiveAnalysisEx](sm-report-displaydescriptiveanalysisex.md) | Generación de un análisis descriptivo. |
| [ExecuteTransientQuery](sm-report-executetransientquery.md) | Ejecuta una consulta y almacena el resultado en una tabla de trabajo |
| [Exportar](sm-report-export.md) | Generación y exportación de un informe |
| [AnálisisDescriptivoExportación](sm-report-exportdescriptiveanalysis.md) | Análisis descriptivo de exportación en curso |
| [GenerateAnalysisWidget](sm-report-generateanalysiswidget.md) | Genere el widget para mostrarlo. |
| [GenerateAndSaveReport](sm-report-generateandsavereport.md) | Genera un informe desde el servidor y lo guarda en la base de datos |
| [GenerateFlatReport](sm-report-generateflatreport.md) | Generación del informe previo utilizado para la exportación |
| [GetAvailableReports](sm-report-getavailablereports.md) | Recupera la lista de informes sin historial |
| [GetAvailableReportsEx](sm-report-getavailablereportsex.md) | Recupera la lista de informes sin su historial, teniendo en cuenta las condiciones de ordenación de datos y la numeración de páginas |

| [GetReportList](sm-report-getreportlist.md) | Obtener la lista de informes disponibles con el historial |
| [GetUsedLanguagesEnum](sm-report-getusedlanguagesenum.md) | Crea una lista desglosada con los idiomas utilizados en la aplicación web. |
| [Publicar](sm-report-publish.md) | Publicación de un informe |
| [RegisterTransientSchema](sm-report-registertransientschema.md) | Guarda un esquema asociado a los resultados de una consulta |
| [Guardar](sm-report-save.md) | Guarda un informe ya generado en la base de datos. |
| [exportSaved](sm-report-exportsaved.md) | Exportar informe guardado de la tabla del historial |
