# CreateExportList

Crea la lista en la que se exportarán las entidades del carro.

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## Parámetros

**etiqueta** etiqueta de la lista

**folderId** ID de la carpeta en la que se creará la lista (0 para usar la carpeta predeterminada).

## Valor(es) devuelto(s)

**listId** ID de la lista recién creada
