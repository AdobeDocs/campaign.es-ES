# toString

Devuelve el contenido de [MemoryBuffer](c-memorybuffer.md) en forma de cadena de caracteres.

```text
toString ( [codePage ])
```

## Parámetros

**codePage** Un entero que codifica la página de caracteres utilizados. De forma predeterminada, MemoryBuffer.CODEPAGE\_UTF8.

## Valor devuelto

El contenido de un sello en forma de cadena de caracteres.
