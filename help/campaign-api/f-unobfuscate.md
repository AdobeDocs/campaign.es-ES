# desproteger

Elimina la ocultación del entero anteriormente ocultado gracias a [ofuscate](f-obfuscate.md).

```text
unobfuscate (value [, version ])
```

## Parámetros

**valor** El entero que se va a proteger.

**versión**: la versión de no ofuscación que se aplicará. 0 de forma predeterminada.

## Valor devuelto

Entero anteriormente ocultado por [obfuscate](f-obfuscate.md).

## Funciones

**Disponible en:**

* Administración de contenido
* Propiedades de envío
* Envío del mensaje
* Regla de tipología
* Importación
* JSSP
* Método SOAP
* WebApp
* Flujo de trabajo
