# GenerateFromId

Genera y publica el contenido al que hace referencia un identificador de una carpeta

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## Parámetros

**id** Identificador de contenido

**publishingDir** Carpeta de publicación

## Valor(es) devuelto(s)

**outputFiles** Lista de archivos generados
