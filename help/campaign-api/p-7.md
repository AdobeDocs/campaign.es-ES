# Guía de migración de E4X

Mozilla abandona progresivamente la extensión E4X para la compatibilidad nativa de XML en JavaScript. Adobe Campaign utilizó ampliamente esta extensión y, por lo tanto, se está preparando para migrar a una solución alternativa.

El objetivo de esta guía es ayudarle a migrar las configuraciones existentes o a desarrollar nuevas configuraciones mediante la descripción de las soluciones de sustitución.

El sistema antiguo y el nuevo coexisten, la versión actual de Adobe Campaign siempre es compatible con E4X, pero las nuevas configuraciones no deben desarrollarse con la extensión E4X.

Recordatorio: E4X añade un tipo de XML de JavaScript que se puede crear directamente desde el programa de origen:

```text
var doc = <xml> ... </xml>
```

o de una cadena:

```text
var doc = new XML ("<xml>...</xml>")
```

A continuación, se puede manipular con una API específica:

```text
element.@id element.where
```

## Tipo XML

El tipo &quot;xml&quot; nativo se reemplaza por una API DOM, que son los tipos [DOMDocument](c-domdocument.md) , [DOMElement](c-domelement.md) , [DOMNode](c-domnode.md), ... lo siguiente es el equivalente de las operaciones más comunes:

> **E4X:**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM:**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X:**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM:**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X:**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM:**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> o
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

Los documentos XML de un JavaScript deben reemplazarse. Cuando este documento se va a utilizar para una función nativa o una llamada de SOAP que pasa un documento XML en parámetro, puede pasar un JSON directamente. Esto se transformará automáticamente en un documento XML (DOMDocument). Si no, siempre puede pasar a través de un objeto JSON, pero se requiere una conversión explícita mediante la función [DOMDocument.fromJXON](m-domdocument-fromjxon.md).

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

Ejemplo de equivalencia entre sintaxis XML y JSON:

> **E4X:**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON:**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

Para obtener más información sobre la sintaxis JSON, consulte la página Uso de XML.

## Llamadas de SOAP

Estos métodos de SOAP deben ejecutar las propiedades del objeto NLWS. El JavaScript ID del esquema se crea a partir del área de nombres y el nombre comienza con una mayúscula. Por ejemplo, el esquema nms:delivery tendrá nmsDelivery como ID de JS.

> **Antiguo:**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **Nuevo:**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## Métodos de SOAP JavaScript

Para recibir un documento XML cuyos parámetros estén en formato DOM en lugar del formato E4X, se debe añadir el atributo dom=&quot;true&quot; al esquema.

## Cadenas multilínea

El uso de XML para generar cadenas multilínea debe reemplazarse por una concatenación de cadenas olvidando agregar el final de la línea \\n.

> **Antiguo:**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **Nuevo:**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## Administración de contenido

Es necesario activar la opción DOM en la plantilla de publicación o desde la plantilla de JavaScript durante la vista previa. Para una transformación XSL con preprocesamiento de JavaScript, también debe activar la opción DOM (ventana de agregador).
