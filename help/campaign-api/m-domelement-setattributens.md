# setAttributeNS

Cambie el valor de un atributo o cree un nuevo atributo.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## Parámetros

URI **namespaceURI** del atributo namespace.

**QualifiedName** Nombre completo del atributo.

**value** Valor de texto de atributo.

## Valor devuelto

Ninguna.
