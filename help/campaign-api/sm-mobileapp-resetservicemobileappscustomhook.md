# resetServiceMobileAppsCustomHook

Borra los parámetros adicionales de los servicios web para todas las aplicaciones móviles en el mismo servicio

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## Parámetros

**serviceContent** Contenido del nodo de servicio actual

## Valor(es) devuelto(s)

**serviceOut**: contenido del nodo de servicio después de procesarlo

**Esquema:** [nms:mobileApp](s-nms-mobileapp.md)
