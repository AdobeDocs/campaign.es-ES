# DeleteCollection

Eliminar una lista de entidades basada en una condición

```text
DeleteCollection ( String schema, XML where, Boolean ignoreDeleteStatus )
```

## Parámetros

**esquema** esquema de entidad

**donde** Eliminar condición

**ignoreDeleteStatus** Omitir deleteStatus

## Valor(es) devuelto(s)

Ninguna.
