# Enumeración (clase)

Representa la definición de una enumeración.

## Propiedades

| Propiedad | Descripción |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Devuelve una cadena de caracteres que proporciona el tipo de lista desglosada. |
| [predeterminado](p-enumeration-default.md) | Devuelve una cadena de caracteres que proporciona el valor predeterminado de la enumeración. |
| [descripción](p-enumeration-description.md) | Devuelve una cadena de caracteres que proporciona una descripción de la enumeración. |
| [hasImage](p-enumeration-hasimage.md) | Devuelve un valor booleano que indica si la enumeración tiene o no una imagen. |
| [etiqueta](p-enumeration-label.md) | Devuelve una cadena de caracteres que proporciona la etiqueta de la enumeración. |
| [nombre](p-enumeration-name.md) | Devuelve una cadena de caracteres que proporciona el nombre de la enumeración. |
| [valores](p-enumeration-values.md) | Devuelve un objeto para el cual cada propiedad es un objeto [EnumerationValue](c-enumerationvalue.md) indizado por su valor. |
