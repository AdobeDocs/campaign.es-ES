# BuildSqlSchema

Genera el código de un esquema a partir de la estructura física de la tabla indicada en los parámetros.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Parámetros

**dataSource** ID del origen de datos

**tableName** Nombre de tabla

## Valor(es) devuelto(s)

**esquema** esquema generado

## Funciones

**Esquema:** [xtk:sqlSchema](s-xtk-sqlschema.md)

**Estático:**

Sí
