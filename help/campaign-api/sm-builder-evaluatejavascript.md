# EvaluateJavaScript

Evaluación del código JavaScript.

```text
XML context = EvaluateJavaScript ( String name, String script, XML context )
```

## Parámetros

**name** Nombre de script.

**script** código de script para ejecutar.

**contexto** Contexto de ejecución de la prueba.

## Valor(es) devuelto(s)

**contexto** Contexto de ejecución de la prueba.
