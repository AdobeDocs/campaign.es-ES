# toXMLString

Convierte el documento XML en una cadena de caracteres.

```text
toXMLString (format)
```

## Parámetros

**formato** Un booleano para dar formato al documento XML.

## Valor devuelto

Ninguna.

## Observaciones

Este método agrega el prólogo, a diferencia del método con el mismo nombre sobre los elementos.
