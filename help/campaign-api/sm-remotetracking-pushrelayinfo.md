# PushRelayInfo

Permite cargar información sobre un envío en los servidores de seguimiento remoto.

```text
PushRelayInfo ( String instance, String dbId, XML document )
```

## Parámetros

**instancia** Nombre de instancia

**dbId** Identificador de base de datos de cliente

**documento** documento que contiene datos

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:remoteTracking](s-nms-remotetracking.md)

**Estático:**

Sí
