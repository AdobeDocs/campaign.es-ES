# CollectLogs

Crea una tabla con todos los mensajes del registro de envíos para una lista de envíos

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## Parámetros

**id** Identificador único de priorización

**envíos** lista de envíos a tener en cuenta

**logTable** tabla que se va a crear para contener todos los mensajes de registro

## Valor(es) devuelto(s)

Ninguna.

**Esquema:** [nms:delivery](s-nms-delivery.md)

**Estático:**

Sí
