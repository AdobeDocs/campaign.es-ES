# BuildOutputNavTree

Combine las definiciones de árbol de navegación que se encuentran en la base de datos con la que se proporciona en el parámetro.

```text
XML navtree = BuildOutputNavTree ( XML navtreeSource, Boolean save )
```

## Parámetros

**navtreeSource** árbol de navegación de Source

**guardar** Guardar el resultado

## Valor(es) devuelto(s)

**navtree** Resultado de la combinación

Sí
