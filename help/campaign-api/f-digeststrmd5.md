# digestStrMd5

> Advertencia:
>
> Esta función no debe utilizarse para crear un hash basado en la información personal.

Calcula la función hash MD5 para una cadena de caracteres. La cadena se codifica automáticamente en UTF-8 antes del cálculo.

```text
digestStrMd5 (string)
```

## Parámetros

**cadena** Cadena para la que se va a calcular la función hash.

## Valor devuelto

El hash MD5 de la cadena pasada como parámetro.
