# appendBase64

Anexa datos de una cadena de caracteres codificada en base 64 al final del búfer.

```text
appendBase64 (string)
```

## Parámetros

**cadena** Una cadena de caracteres que representa los datos binarios codificados en base 64 para agregarlos al búfer.

## Valor devuelto

Ninguna.
