# enameNode

Cambia el nombre de un elemento o un atributo.

```text
renameNode (node, namespaceURI, qualifiedName)
```

## Parámetros

**nodo**: nodo de tipo elemento/atributo.

**namespaceURI** Nuevo URI de área de nombres.

**QualifiedName** Nuevo nombre calificado.

## Valor devuelto

Nodo cambiado. Puede ser el nodo especificado o un nodo que reemplace al anterior.
